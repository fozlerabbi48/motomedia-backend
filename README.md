# 🏍️ MotoMedia Backend

Backend API for MotoMedia, a motorcycle social media platform.

## 🚀 Features

- Create motorcycle posts
- Upload post images
- Like posts
- Comment on posts
- Get all posts
- MongoDB database
- Express.js REST API
- Multer image upload

## 🛠️ Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- Nodemon
